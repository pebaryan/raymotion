# `.as` API parity audit

## Target

AngelScript is the full composition authoring path. Every public engine operation that changes composition content, evaluates authored data, or draws authored content must have an equivalent `.as` operation. A descriptor or callback may replace a C++ signature if it preserves behavior and documents script limits. Graphics lifecycle, output encoding, backend registration and CLI operations remain host responsibilities.

The audit is semantic, not a name search. For each public header, compare builders, fields, queries, transforms, render calls and callbacks with registrations and implementations in `src/engine/script_angelscript.cpp` and `src/engine/script.cpp`; document aliases, limits, callback signatures and host-only classifications here and in `docs/scripting.md`.

## Audit status

The current public-header pass covers all 48 headers in `include/rmtn/`. No unmatched content-authoring operation remains in this pass. The parity target is composition content authoring and authored-data evaluation/drawing; process/CLI, graphics resource lifecycle, backend registration, frame presentation, and completed-composition output encoding/mixing remain host responsibilities. In particular, native `tts::Script::attach(TNode*)` maps to script voiceover declarations (`tts::speak`) and `tts::nestCue`, while `media::mixAudio(Comp)` consumes the host-owned completed composition and is output rendering rather than script-authored audio placement. Script audio cues, envelopes, PCM decode, and WAV asset writing are available.

## Callback contracts

| Native callback | Script route | Mapping |
|---|---|---|
| Rig clips, outfit paint/sample, flex parts and character softness | Clip descriptors, `partFunction`, `softnessFormula`/`softnessFunction`, outfit callbacks | Named callbacks use local seconds, frame, texture region or UV as documented by each route. |
| Crowd goals, paths and looks | `goalFunction`, `pathFunction`, `lookFunction` | Deterministic callbacks return vectors or look descriptors during baking. |
| Physics pins and collider drive | `pinFunction`, `pinEndFunction`, `driveFunction` | Named vector callbacks use absolute simulation seconds and fixed-step solver sampling. |
| Scene, camera and light animation | `Scene3D.up`, `cameraFunction`, `lightFunction`, `g3d::upObject` | Callbacks set absolute values from local frame; camera/light fields follow the matching native state order. |
| CityJSON look | `colorFunction`, `materialFunction` | Callback receives serialized object/face data and returns color, material JSON or null as documented. |
| Custom interpolation and transitions | `anim::interpolateFunction`, `sceneTransitionFunction`, text reveal/morph callbacks | Named scalar callback receives progress and returns finite eased progress. |
