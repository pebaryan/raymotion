# German CEFR banner videos

Status: **template-grade promotional banners**, not lesson films.

- **18 videos**: 6 levels x 3 tracks (Grammatik, Wortschatz, Situationen).
- **1200 x 400**, 30 fps, **6 s**, H.264/AAC.
- Voice-free: animated level/title list, shared BGM and sparse SFX.
- Titles: `assets/data/german-cefr/banners.json`, derived from `video-titles.csv`.
- Composition: `examples/showcase/german_cefr_banners.cpp`.
- Deliverables: `output/german-cefr/banners/` plus `manifest.json`.
- Still reference: `out/banner-a1-grammatik.png`, `out/banner-b1-wortschatz.png`, `out/banner-c2-situationen.png`.

These are promotional shells using the series visual system. They do not add individual
lesson proof objects, language review or per-banner QC.
