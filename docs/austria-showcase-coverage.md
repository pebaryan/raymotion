# Austria film — raymotion feature coverage

The goal is an Austria history film that also demonstrates the engine. The current
`austria-through-time` render is a 72.3-second narrated cut, not the complete feature showcase.
This inventory follows the feature families in `README.md` and keeps production work
aligned with that larger goal.
